# Источники и правила доказательности

Исходники сохранены без исправления содержания. ZIP распакован только в три Markdown-стенограммы; код Java прочитан, но не исполнялся. URL и SHA-256 записаны в [manifest.json](manifest.json).

| ID | Источник | Что он доказывает и где предел |
|---|---|---|
| E00 | [Текст задания](assignment-extract.md), [встроенная схема](assignment-as-is.png) | Контекст, ограничения, цели трёх месяцев и года; не измеренные эксплуатационные характеристики |
| E01 | [Бизнес-спонсор](interview-business.md) | Заявленные цели и допустимость изменений; без количественных target/baseline |
| E02 | [Руководитель поддержки](interview-support.md) | Наблюдения о расхождениях и ручной работе; без частот инцидентов и выгрузки обращений |
| E03 | [Техлид ядра](interview-1-tech-lead.md) | Объяснение логики, Oracle, транзакций и рисков; требуется проверка runtime и репозитория |
| E04 | [Разработчик логистики](interview-2-logistics.md) | Смешанные интеграции, дубли, исключения, правила в нескольких слоях |
| E05 | [Разработчик аналитики](interview-3-analytics.md) | Прямые SQL/выгрузки, разные трактовки, нагрузка, неполный lineage |
| E06 | [OrderProcessingService.java](OrderProcessingService.java) | Конкретный демонстрационный метод и порядок вызовов; не вся система и не работающая production-версия |
| E07 | [Предоставленная AS-IS.puml](AS-IS.puml) | Историческое представление связей; неполное, смешивает уровни контекста и компонентов |

В документах используются четыре статуса: **подтверждено источником** (наблюдение/заявление с указанной областью), **гипотеза** (нужна проверка), **пробел** (данных нет), **предложение** (решение проекта). «Подтверждено интервью» не означает «измерено на production». Сценарии будущих интервью не выдаются за проведённые встречи. Комментарии к коду и готовые «наблюдения» в стенограммах сверяются с телом источника.
